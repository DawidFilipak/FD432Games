About the studio

FD432Games is an independent game studio from Poland. We design, code and polish our games ourselves — from the first prototype to the store page.

We like games that explain themselves in one tap: aim, shoot and let physics do the rest. They're free, work offline and fit a two-minute break just as well as a long evening.
